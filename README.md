## Описание проекта
В рамках данного курса проектируется и разрабатывается база данных для системы "Интернет-магазин". База данных предназначена для хранения информации о пользователях, каталоге товаров, заказах, а также для обеспечения ролевой модели доступа (RBAC) к системе.

Вся документация по проекту находится в директории `docs/`.
