# Функциональные требования к проекту "Интернет-магазин"

Проект представляет собой бэкенд-часть для интернет-магазина. Основной упор делается на управление каталогом, заказами и правами доступа пользователей.

## Минимальные ОБЯЗАТЕЛЬНЫЕ функциональные требования:

1. **Авторизация и аутентификация пользователя**
   - Вход в систему по связке email и пароля.
   
2. **Управление пользователями (CRUD)**
   - Создание нового пользователя (регистрация) и связанного с ним профиля.
   - Чтение информации о профиле пользователя.
   - Обновление данных (смена пароля, обновление контактов в профиле).
   - Удаление пользователей реализовано через механизм **Soft Delete** (аккаунт помечается как удаленный, но остается в БД для целостности истории).
   - Возможность блокировки (бана) пользователей.

3. **Система ролей (RBAC)**
   - Реализована ролевая модель управления доступом.
   - Доступ к функциям системы предоставляется на основе атомарных разрешений.
   - Роли выступают в качестве контейнеров для набора разрешений.

4. **Журналирование действий пользователя**
   - В системе ведется аудит-лог.
   - Фиксируются ключевые действия (вход, создание заказа и т.д.).
